# Запечённый свет и рельеф карты (хаки H-02 и H-05)

Код: `crates/rm_assets/src/heightbake.rs`.

## Зачем

Карта кампании в Medieval II не освещается в реальном времени. Свет,
тени гор и мелкий рельеф посчитаны заранее и лежат в текстурах; игра
их только читает. Это дешевле любого динамического освещения и даёт
стабильную картинку. Динамический свет на карте кампании запрещён
реестром хаков ([smart-hacks.md](../adr/smart-hacks.md)).

## Карта высот

`Heightmap` — сетка высот в метрах, строки сверху вниз, как у
`map_heights.tga` из оригинала.

- `Heightmap::from_image(картинка, min, max)` — из серой картинки
  (например, прочитанной `Image::from_tga`): яркость 0 → `min` метров,
  255 → `max`.
- `Heightmap::procedural(…)` — холмы из шума для примеров и тестов.

## Горы выше, чем «по правде» (H-05)

`exaggerate_mountains(порог, множитель)` растягивает по высоте всё, что
выше порога; равнины не трогает. С множителем 2–3 горы хорошо читаются
сверху и меньше мерцают на расстоянии.

## Normal map

`normal_map(карта, размер_клетки)` — для каждой клетки берётся разница
высот соседей слева-справа и сверху-снизу; из неё получается наклон
поверхности (нормаль). Нормаль записывается в цвет: `RGB = n * 0.5 + 0.5`,
ось «вверх» — в зелёном канале. Плоская земля — цвет `(128, 255, 128)`.

## Lightmap

`lightmap(карта, размер_клетки, солнце)` — яркость каждой клетки:

1. **рассеянный свет неба** — 0,35, есть везде;
2. **солнце** — по закону Ламберта: чем прямее склон смотрит на
   солнце, тем светлее;
3. **тень** — из клетки «пускается луч» к солнцу по сетке. Если по
   дороге встретилась точка выше луча, клетка в тени и получает только
   рассеянный свет. Луч прекращается, когда поднялся выше самой высокой
   горы или вышел за карту.

Результат — серая картинка. Шейдер карты умножает цвет почвы на неё.

Пример (сборщик с `--preview` кладёт его в `demo_lightmap.tga` и
`demo_normals.tga`): карта 256×256, горы ×2,5, солнце низко с северо-запада.
