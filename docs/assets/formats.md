# Форматы файлов: TGA, .rmpak, OBJ

Код: `crates/rm_assets/src/image.rs`, `src/pack.rs`, `src/obj.rs`.

## TGA — картинки

Medieval II хранит в TGA карты кампании (`map_heights.tga`,
`map_regions.tga`, `map_climates.tga`…) и многие текстуры. Чтобы моддер
мог открыть наши текстуры тем же редактором, а мы — прочитать его карты,
крейт понимает TGA сам, без библиотек.

- **Запись** (`Image::to_tga`): несжатый 32-битный TGA, строки сверху вниз.
- **Чтение** (`Image::from_tga`): цветной 24/32 бита и серый 8 бит, без
  сжатия и со сжатием RLE, строки снизу вверх (классика) или сверху вниз.
  Палитровые TGA не поддерживаются. Повреждённый или обрезанный файл даёт
  понятную ошибку, а не падение.

## .rmpak — пакет ассетов

Один файл, в котором лежат все атласы и LOD-цепочки. Игра будет читать
его вместо того, чтобы собирать ассеты при каждом запуске.

**Пакет — производный кэш.** По правилу 4
[контракта моддинга](../adr/modding-contract.md) он не лежит в
репозитории, строится сборщиком `rm_assetc` и пересобирается в любой
момент. Источник правды — код (а позже — исходные файлы художника).

### Раскладка

Все числа little-endian.

```text
"RMPK"            4 байта, подпись
u16 версия        сейчас 1
u16 флаги         0
u32 число записей
оглавление, для каждой записи:
    u8  вид          1 картинка, 2 меш, 3 атлас, 4 LOD-цепочка, 5 текст
    u16 длина имени, имя в UTF-8
    u64 смещение данных от начала файла
    u64 длина данных
    u64 хеш FNV-1a данных
данные записей подряд
```

Содержимое записей:

| Вид | Данные |
|---|---|
| картинка | `u32 ширина, u32 высота`, пиксели RGBA по строкам сверху вниз |
| меш | `u32 вершин, u32 индексов`, вершины по 9 `f32` (позиция, нормаль, UV, окраска), индексы `u32` |
| атлас | картинка, `u32 число кусков`, для каждого: имя, `u32 x, y, w, h` |
| LOD-цепочка | `u32 уровней`, для каждого: `f32 порог`, `u8 0` + меш или `u8 1` + `f32 ширина, высота` + `f32 u0, v0, u1, v1` |
| текст | байты UTF-8 |

### Имена записей

| Имя | Что |
|---|---|
| `manifest` | текстовое описание: атласы, модели, треугольники по уровням |
| `atlas/materials` | атлас материалов |
| `atlas/masks` | атлас масок грязи/снега/крови |
| `atlas/impostors` | атлас импосторов |
| `model/<имя>` | LOD-цепочка модели, например `model/spearman` |

### Защита от порчи

При чтении (`Pack::parse`) проверяется подпись, версия и хеш каждой
записи; все счётчики сверяются с реальным размером файла, поэтому
испорченный пакет не заставит выделить гигабайты памяти. Ошибка говорит,
что именно не так, например: «запись «model/church» повреждена (не
сходится хеш)» или «версия 2, а сборка читает версию 1; пересоберите
пакет rm_assetc».

### Воспроизводимость

Сборка дважды с одним зерном даёт одинаковые байты (тест
`build_is_deterministic`). Тригонометрия берётся из `rm_core::dmath`,
шум — только целочисленный, поэтому пакет должен совпадать и между
Windows и Linux.

## OBJ — для просмотра

`rm_assetc build --preview` выгружает каждую модель на каждом уровне в
`<модель>_lod<N>.obj` с файлом материала `materials.mtl`, который
ссылается на `materials.tga`. OBJ открывается в Blender и в «Средстве
просмотра 3D» Windows — модели можно посмотреть, не запуская игру.

## Совместимость с оригиналом

Оригинальные форматы моделей M2 (`.mesh`) и упакованные текстуры
(`.texture`/DDS) пока не читаются: своих моделей в этих форматах у нас нет,
а чужие класть в репозиторий нельзя. Когда понадобится подключать данные
игрока, читатель добавится сюда же, рядом с TGA.
