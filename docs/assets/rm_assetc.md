# rm_assetc — сборщик ассетов

Код: `crates/rm_assets/src/bin/rm_assetc.rs`.

Небольшая программа командной строки: собирает пакет ассетов и
показывает, что в нём лежит.

## Собрать пакет

```sh
cargo run --release -p rm_assets --bin rm_assetc -- build
```

Получится `assets/assets.rmpak` (около 4,5 МБ). Папка `assets/` в корне
не попадает в git: пакет — производный файл.

Ключи:

| Ключ | Что делает | По умолчанию |
|---|---|---|
| `--out ПАПКА` | куда положить пакет | `assets` |
| `--seed ЧИСЛО` | зерно процедурной генерации | `1066` |
| `--size ПИКСЕЛИ` | сторона текстуры материала (степень двойки, 8–1024) | `128` |
| `--preview` | ещё выгрузить картинки и модели для просмотра | выключено |

## Посмотреть глазами

```sh
cargo run --release -p rm_assets --bin rm_assetc -- build --preview
```

В `assets/preview/` появятся:

| Файл | Что |
|---|---|
| `materials.tga` | атлас материалов |
| `masks.tga` | атлас масок (R грязь, G снег, B кровь) |
| `impostors.tga` | атлас импосторов (прозрачный фон) |
| `<модель>_lod0.obj` … `_lod2.obj` | модели на каждом уровне, с текстурой |
| `materials.mtl` | материал для OBJ |
| `demo_normals.tga`, `demo_lightmap.tga` | пример запечённой карты высот |

TGA открывается в GIMP, Paint.NET, Photoshop; OBJ — в Blender или
«Средстве просмотра 3D» Windows.

## Что в пакете

```sh
cargo run --release -p rm_assets --bin rm_assetc -- info assets/assets.rmpak
```

Печатает оглавление (вид, имя, размер каждой записи) и манифест:
размеры атласов и для каждой модели — треугольники и порог каждого
уровня, например `model spearman tris 152@30 72@80 36@200 2@1200`.

Ошибки печатаются по-русски с причиной, код выхода не ноль.
