# Как рисуется один кадр

Код: `crates/rm_app/src/render/mod.rs`, функция `Renderer::draw_frame`.

## Главная сложность: CPU и GPU работают параллельно

Процессор записывает команды, видеокарта их выполняет позже и в своём
темпе. Чтобы они не мешали друг другу, используются два вида «светофоров»:

- **Семафор** — светофор между операциями на GPU (например, «картинка
  освободилась» → «можно рисовать» → «нарисовано» → «можно показывать»).
- **Забор (fence)** — светофор между GPU и CPU: процессор ждёт, пока
  видеокарта закончит работу.

## Кадры «в полёте»

Пока видеокарта рисует кадр N, процессор уже готовит кадр N+1.
Таких кадров одновременно не больше двух (`FRAMES_IN_FLIGHT = 2`). У каждого
свой буфер команд, свой семафор и свой забор.

## Пять шагов кадра

1. **Ждём забор** своего слота: видеокарта закончила кадр, который рисовался
   в нём два кадра назад, и буфер команд можно переиспользовать.
2. **Берём картинку** из swapchain (`acquire_next_image`). Когда она реально
   освободится, GPU поднимет семафор `image_available`.
3. **Записываем команды**: начать проход рендера (render pass) и закончить.
   Проход сам заливает картинку цветом фона (`load_op = CLEAR`) и переводит
   её в состояние «готова к показу». Сюда позже добавятся команды рисования
   карты, юнитов и интерфейса.
4. **Отправляем** команды в очередь: начать после `image_available`, по
   окончании поднять `render_finished` и забор слота.
5. **Показываем** картинку (`queue_present`) после `render_finished`.

Семафоров `render_finished` по одному на каждую картинку swapchain, а не на
слот кадра: так один и тот же семафор не используется повторно, пока
система ещё показывает предыдущую картинку (известная ловушка Vulkan).

## Изменение размера окна

Swapchain жёстко привязан к размеру окна. Когда размер меняется, или Vulkan
отвечает `ERROR_OUT_OF_DATE_KHR` / «suboptimal», мы ставим флаг
`needs_recreate`. Перед следующим кадром рендер дожидается, пока GPU всё
доделает, и пересоздаёт swapchain, framebuffer'ы и семафоры. Свёрнутое
окно (0×0) не рисуется вовсе.

## Проверено

На программном Vulkan (llvmpipe) со слоями проверки: сотни кадров и
несколько ресайзов подряд без единого предупреждения.
