# Как запустить Reforged Medieval

## Вариант 1. Скачать готовую сборку (без установки Rust)

1. Откройте репозиторий на GitHub → вкладка **Actions**.
2. Выберите последний зелёный запуск **CI** (для ветки `main` или нужного PR).
3. Внизу страницы, в блоке **Artifacts**, скачайте:
   - `reforged-medieval-windows` — для Windows;
   - `reforged-medieval-linux` — для Linux.
4. Распакуйте zip целиком (рядом с программой должна лежать папка `data`)
   и запустите `reforged-medieval.exe` (Windows) или `./reforged-medieval`
   (Linux; может понадобиться `chmod +x reforged-medieval`).

Скачивание артефактов требует входа в GitHub. Хранятся они 90 дней.

Windows может предупредить о «неизвестном издателе» (SmartScreen): программа
не подписана сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Что должно получиться

Откроется окно с полевой битвой. Ваша армия (синие, Northmark) стоит на юге:
две роты ополчения, две роты копейщиков в первой линии и два отряда
арбалетчиков во второй. Напротив, на севере, армия Southreach (красные):
четыре роты ополчения, рота копейщиков, два отряда арбалетчиков и два
отряда конных лучников. Врагов больше: если просто бросить всех в атаку,
скорее всего проиграете. Противником
управляет ИИ: он сам пойдёт в атаку. Задача — обратить врага в бегство.
Внизу экрана — карточки ваших отрядов: число солдат, что отряд делает и
полоска морали. Наверху — силы сторон и время боя.

### Управление

| Действие | Как |
|---|---|
| Выбрать отряд | левый щелчок по солдатам или по карточке внизу; клавиши 1–9 |
| Выбрать несколько | рамка левой кнопкой; Shift или Ctrl + щелчок добавляет; Ctrl+A — все |
| Идти | правый щелчок по земле |
| Встать в линию | правой кнопкой протянуть линию фронта по земле |
| Атаковать | правый щелчок по вражескому отряду (над ним появится «АТАКА») |
| Бегом | двойной правый щелчок (и для движения, и для атаки) |
| Остановиться | Backspace |
| Камера | WASD или стрелки (Shift — быстрее), Q/E — поворот, колесо — приближение, зажатое колесо — вращение, Home — вернуться к армии |
| Пауза / скорость | Пробел; `+` и `-` — быстрее и медленнее (до ×8) |
| Подсказка | F1 — спрятать или показать |
| Новая битва | Enter после окончания или F5 в любой момент |
| Выход | Esc (если что-то выделено, первый Esc снимает выделение) |

Советы: копейщики держат удар и бьют конницу, ополчение быстро бежит при
потерях, арбалетчики сильны издалека, но слабы в рукопашной. Удар во фланг
или в тыл сильно бьёт по морали. Разгон бегом перед ударом даёт бонус
натиска.

В заголовке окна раз в секунду обновляются кадры в секунду (FPS), шаги
симуляции в секунду (20 при обычной скорости) и имя видеокарты.

## Требования

- Windows 10/11 или Linux (X11 или Wayland).
- Видеокарта с поддержкой Vulkan 1.1 и свежий драйвер. Vulkan входит в
  обычный драйвер NVIDIA, AMD и Intel, отдельно ставить ничего не нужно.

## Параметры запуска

```
reforged-medieval --help
```

| Параметр | Что делает |
|---|---|
| `--tick-rate 30` | частота симуляции, тиков в секунду (по умолчанию 20) |
| `--no-vsync` | не ждать вертикальную синхронизацию, FPS выше частоты монитора |
| `--frames 300` | закрыться после 300 кадров |
| `--width 1920 --height 1080` | размер окна |
| `--demo` | обе армии под управлением ИИ: смотреть бой со стороны |
| `--seed 7` | другое зерно случайности (тот же seed — тот же бой при тех же приказах) |
| `--data путь` | взять данные из другой папки (например, мод) |

Переменные окружения: `RUST_LOG=debug` — подробный журнал в консоль;
`RM_VALIDATION=1` — включить слои проверки Vulkan (нужен установленный
[Vulkan SDK](https://vulkan.lunarg.com/)).

## Если не запускается

| Сообщение | Что делать |
|---|---|
| «не найдена библиотека Vulkan» | Обновите драйвер видеокарты |
| «не найдена видеокарта с поддержкой Vulkan» | Видеокарта слишком старая или драйвер без Vulkan |
| «не найдена папка data/» | Распакуйте архив целиком: папка `data` должна лежать рядом с программой |
| «ошибки в данных» | В файле из `data/` опечатка; в сообщении указаны файл и строка |
| Окно мигает и закрывается | Запустите из консоли (`cmd` или терминал) и пришлите текст ошибки |

## Вариант 2. Собрать из исходников

1. Установите Rust: <https://rustup.rs> (на Windows rustup предложит
   поставить Visual Studio Build Tools — соглашайтесь).
2. В папке репозитория выполните:

```
cargo run --release
```

Запуск тестов: `cargo test --workspace`.
