# Как запустить Reforged Medieval

## Вариант 1. Скачать готовую сборку (без установки Rust)

1. Откройте репозиторий на GitHub → вкладка **Actions**.
2. Выберите последний зелёный запуск **CI** (для ветки `main` или нужного PR).
3. Внизу страницы, в блоке **Artifacts**, скачайте:
   - `reforged-medieval-windows` — для Windows;
   - `reforged-medieval-linux` — для Linux.
4. Распакуйте zip и запустите `reforged-medieval.exe` (Windows) или
   `./reforged-medieval` (Linux; может понадобиться `chmod +x reforged-medieval`).

Скачивание артефактов требует входа в GitHub. Хранятся они 90 дней.

Windows может предупредить о «неизвестном издателе» (SmartScreen): программа
не подписана сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».

## Что должно получиться

Откроется окно 1280×720, фон медленно меняет цвет от тёмно-синего к
золотистому и обратно. В заголовке окна раз в секунду обновляются:
кадры в секунду (FPS), тики симуляции в секунду (должно быть 20) и имя
видеокарты. Окно можно растягивать и сворачивать. **Esc** — выход.

## Требования

- Windows 10/11 или Linux (X11 или Wayland).
- Видеокарта с поддержкой Vulkan 1.1 и свежий драйвер. Vulkan входит в
  обычный драйвер NVIDIA, AMD и Intel, отдельно ставить ничего не нужно.

## Параметры запуска

```
reforged-medieval --help
```

| Параметр | Что делает |
|---|---|
| `--tick-rate 30` | частота симуляции, тиков в секунду (по умолчанию 20) |
| `--no-vsync` | не ждать вертикальную синхронизацию, FPS выше частоты монитора |
| `--frames 300` | закрыться после 300 кадров |
| `--width 1920 --height 1080` | размер окна |

Переменные окружения: `RUST_LOG=debug` — подробный журнал в консоль;
`RM_VALIDATION=1` — включить слои проверки Vulkan (нужен установленный
[Vulkan SDK](https://vulkan.lunarg.com/)).

## Если не запускается

| Сообщение | Что делать |
|---|---|
| «не найдена библиотека Vulkan» | Обновите драйвер видеокарты |
| «не найдена видеокарта с поддержкой Vulkan» | Видеокарта слишком старая или драйвер без Vulkan |
| Окно мигает и закрывается | Запустите из консоли (`cmd` или терминал) и пришлите текст ошибки |

## Вариант 2. Собрать из исходников

1. Установите Rust: <https://rustup.rs> (на Windows rustup предложит
   поставить Visual Studio Build Tools — соглашайтесь).
2. В папке репозитория выполните:

```
cargo run --release
```

Запуск тестов: `cargo test --workspace`.
