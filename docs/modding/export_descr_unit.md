# `export_descr_unit.txt` — юниты

Файл описывает все отряды игры: из кого состоит отряд, чем он воюет, насколько
он крепок и сколько стоит. Лежит в `data/export_descr_unit.txt`.

## Пример

```
type             Shield Wall Spearmen
dictionary       Shield_Wall_Spearmen ; Копейщики стены щитов
category         infantry
class            spearmen
voice_type       Heavy_1
banner faction   main_spearmen
soldier          spearman_northern, 60, 0, 1
officer          officer_northern
attributes       sea_faring, hide_forest, can_withdraw
formation        1, 1.2, 2, 2.4, 4, square, schiltrom
stat_health      1, 0
stat_pri         5, 3, no, 0, 0, melee, simple, piercing, spear, 25, 1
stat_pri_armour  4, 4, 4, metal
stat_mental      6, disciplined, trained
stat_charge_dist 30
stat_cost        1, 380, 140, 70, 60, 380, 4, 380
ownership        northmark
```

Каждый юнит начинается со строки `type`. Порядок остальных полей внутри юнита
не важен, но привычнее держать его как в примере.

## Поля

**Обяз.** — без этого поля юнит не загрузится.

| Поле | Обяз. | Значение |
|---|---|---|
| `type` | да | Внутреннее имя юнита. Может содержать пробелы. На него ссылаются другие файлы. Должно быть уникальным. |
| `dictionary` | да | Ключ текста с названием юнита для интерфейса. Одно слово. |
| `category` | да | Род войск: `infantry`, `cavalry`, `siege`, `handler`, `ship`, `non_combatant`. |
| `class` | да | Класс: `light`, `heavy`, `missile`, `spearmen`, `skirmish`. |
| `voice_type` | нет | Набор голосов отряда. Одно слово. |
| `banner faction` | нет | Знамя отряда. |
| `banner holy` | нет | Знамя для крестовых походов. |
| `soldier` | да | `модель, число солдат, доп. фигуры[, масса]`. Масса по умолчанию `1`; она влияет на то, как солдаты расталкивают друг друга. |
| `officer` | нет | Модель офицера. Можно указать несколько строк `officer`. |
| `mount` | нет | Ездовое животное, например `steppe pony`. |
| `attributes` | нет | Список особенностей через запятую: `sea_faring`, `hide_forest`, `can_withdraw` и т. п. |
| `formation` | нет | `интервал сбоку, интервал сзади (плотный строй), интервал сбоку, интервал сзади (рассыпной строй), число шеренг, построение[, построение…]`. Построения: `square`, `wedge`, `horde`, `schiltrom` и т. п. |
| `stat_health` | да | `здоровье солдата, здоровье животного`. |
| `stat_pri` | да | Основное оружие, см. ниже. |
| `stat_sec` | нет | Второе оружие, тот же формат. |
| `stat_pri_armour` | да | `броня, навык защиты, щит, звук попадания` (звук: `flesh`, `leather`, `metal`). |
| `stat_mental` | да | `мораль, дисциплина, выучка[, флаги]`. Дисциплина: `low`, `normal`, `disciplined`, `impetuous`, `berserker`. Выучка: `untrained`, `trained`, `highly_trained`. Флаг, например, `lock_morale`. |
| `stat_charge_dist` | нет | С какой дистанции отряд переходит на бег в атаке. |
| `stat_cost` | да | 8 чисел, см. ниже. |
| `ownership` | да | Фракции, которые могут нанимать юнит, через запятую. Каждая должна быть в `descr_sm_factions.txt`; `slave` (мятежники) можно не объявлять. |

Любое другое поле (например, `stat_heat` или `era 0` из оригинала) не ломает
загрузку: оно сохраняется, но игра его пока не использует, и проверка выведет
предупреждение.

### Оружие: `stat_pri` и `stat_sec`

```
stat_pri  7, 2, crossbow_bolt, 120, 25, missile, crossbow, piercing, none, 25, 1
          │  │  │              │    │   │        │         │         │     │   └ коэффициент скелета (необяз., 1)
          │  │  │              │    │   │        │         │         │     └ задержка между ударами (необяз., 25)
          │  │  │              │    │   │        │         │         └ звук оружия
          │  │  │              │    │   │        │         └ тип урона: piercing, blunt, slashing, fire
          │  │  │              │    │   │        └ технология: simple, archery, crossbow, …
          │  │  │              │    │   └ тип оружия: melee, missile, thrown, siege_missile, no
          │  │  │              │    └ боезапас
          │  │  │              └ дальность
          │  │  └ снаряд (`no`, если оружие ближнего боя)
          │  └ бонус натиска
          └ атака
```

### Стоимость: `stat_cost`

```
stat_cost  1, 420, 160, 80, 60, 420, 4, 420
           │  │    │    │   │   │    │  └ штраф за превышение лимита в своей битве
           │  │    │    │   │   │    └ лимит отрядов в своей битве
           │  │    │    │   │   └ цена в своей битве
           │  │    │    │   └ цена улучшения брони
           │  │    │    └ цена улучшения оружия
           │  │    └ содержание за ход
           │  └ цена найма
           └ сколько ходов нанимается
```

## Частые ошибки

| Сообщение | Что значит |
|---|---|
| `в записи `X` нет обязательного поля `stat_cost`` | Забыли поле. Номер строки указывает на `type` этого юнита. |
| `в `soldier`: число солдат должно быть числом, а написано `sixty`` | Вместо числа слово или опечатка. |
| `в `stat_pri` ожидается не меньше 9 значений через запятую` | Пропущена запятая или значение. |
| `неизвестная категория `dragons`` | Допустимые значения перечислены прямо в сообщении. |
| `поле `class` повторяется` | Одно и то же поле дважды в одном юните. |
| `юнит `X` уже объявлен на строке N` | Два юнита с одинаковым `type`. |
| `фракция `X` из `ownership` не объявлена` | Опечатка в имени фракции или фракции нет в `descr_sm_factions.txt`. |
