# Документация Reforged Medieval

Документация пишется простым языком: что делает код, почему он устроен
именно так и где его найти. Каждая часть проекта ведёт свой раздел.

| Раздел | О чём |
|---|---|
| [Как запустить](how-to-run.md) | Скачать готовую сборку или собрать самому |
| [app/](app/README.md) | Приложение: окно, Vulkan, главный цикл, рендер битвы, управление, CI |
| [adr/](adr/) | Архитектурные решения (ADR) и бюджеты производительности |
| [battle/](battle/README.md) | Битва: движение, бой, мораль, ИИ (`crates/rm_battle`, `crates/rm_battle_ai`) |
| [core/](core/) | Ядро симуляции на ECS (`crates/rm_core`) |
| [data/](data/) | Чтение текстовых файлов данных (`crates/rm_data`) |
| [modding/](modding/) | Как менять игру через текстовые файлы |

Если раздела ещё нет по ссылке — его пишет соседняя команда, и он
появится после слияния её изменений.
