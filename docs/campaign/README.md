# Кампания: как устроен крейт `rm_campaign`

Этот раздел объясняет простыми словами, как работают базовые правила
кампании: кто когда ходит, откуда берутся деньги, как армии ходят по карте
и воюют. Как менять эти правила через текстовые файлы — в
[руководстве для моддеров](../modding/campaign.md).

## Что уже есть

- **Фракции ходят по очереди** — в том порядке, в каком они записаны в
  `descr_strat.txt`. Круг, в котором сходили все, — это один ход кампании.
- **Регионы и поселения.** В каждом регионе одно поселение; у поселения
  есть владелец, уровень (`village`, `town`, …) и население.
- **Экономика.** В начале своего хода фракция получает налоги, доход с ферм,
  торговли и «кошелёк короля» и платит за содержание армий.
- **Найм.** Поселение обучает отряды; деньги списываются сразу, отряд
  появляется через `recruit_turns` ходов.
- **Армии** переходят между соседними регионами. Встреча с чужой армией —
  автобой, вход в чужой регион без защитников — захват поселения.
- **Конец кампании** — когда прошла дата `end_date` или осталась одна
  фракция (мятежники не считаются).

Чего пока нет (сделают следующие этапы): постройки, дипломатия (сейчас все
воюют со всеми), осады, персонажи и их черты, религия, порядок и бунты,
флот, настоящий ИИ кампании (`rm_campaign_ai`). Отрисовка карты — забота
`rm_campaign_map`, этот крейт отвечает только за состояние кампании.

## Карта файлов

| Файл | Что делает |
|---|---|
| `crates/rm_campaign/src/lib.rs` | Точка входа: `Campaign` — вся кампания, запуск, очередь ходов, чтение состояния, хеш. |
| `crates/rm_campaign/src/economy.rs` | Найм, рост населения, доход и содержание армий. |
| `crates/rm_campaign/src/army.rs` | Переходы армий, автобой, захват поселений. |
| `crates/rm_campaign/src/map.rs` | Граф регионов: соседи, поиск пути, ближайший регион к клетке. |
| `crates/rm_campaign/src/components.rs` | Компоненты ECS: поселение, армия, владелец, место, переходы, очередь найма. |
| `crates/rm_campaign/src/command.rs` | Команды (`MoveArmy`, `Recruit`), их ошибки и события кампании. |
| `crates/rm_campaign/src/ids.rs` | Короткие номера фракций, регионов и типов юнитов. |
| `crates/rm_campaign/src/autoplay.rs` | Временный «автопилот» для фракций, пока нет ИИ кампании. |
| `crates/rm_campaign/src/tests.rs` | Тесты правил на маленькой карте из трёх регионов. |
| `crates/rm_campaign/tests/headless_campaign.rs` | 30 ходов на настоящих данных без окна + повтор по командам. |
| `crates/rm_campaign/examples/headless.rs` | Пример: прогон кампании с летописью в консоли. |

Файлы данных читает `rm_data` (новые модули `region.rs`, `resource.rs`,
`strat.rs`, `campaign.rs`; всё вместе загружает `CampaignData::load_dir`).

Подробнее:

- [turn.md](turn.md) — как проходит ход и откуда берутся числа (формулы);
- [armies.md](armies.md) — движение, автобой, захват;
- [design.md](design.md) — как кампания лежит в ECS и почему она детерминирована.

## Как посмотреть своими глазами

Из корня репозитория:

```text
cargo run -p rm_campaign --example headless -- 20
```

Фракции 20 ходов играют на автопилоте, в консоль печатается летопись:

```text
=== Ход 1 — лето 1080 года ===
-- ходит northmark
   доход: налоги 96 + фермы 150 + торговля 105 + кошелёк 1200 − армии 460 = +1091, в казне 5091
   армия идёт: Ostmark → Hollowmere
   northmark захватывает Hollowmere у slave
```

Аргументы: число ходов, seed, папка данных (`... -- 20 7 data`).
С одним и тем же seed летопись всегда одинаковая.

## Как этим пользоваться из кода

```rust
use std::path::Path;
use rm_campaign::{Campaign, Command};
use rm_data::CampaignData;

let data = CampaignData::load_dir(Path::new("data"))?;
let mut campaign = Campaign::new(&data, 42)?;          // seed = 42

let me = campaign.current_faction();                   // чей ход
let army = campaign.armies().into_iter().find(|a| a.owner == me).unwrap();
let to = campaign.map().region(army.region).neighbours[0];
campaign.apply(Command::MoveArmy { army: army.entity, to })?;

campaign.end_turn();                                    // ход следующей фракции
for event in campaign.drain_events() {
    println!("{event:?}");                              // что произошло
}
```

Интерфейс и рендер карты только **читают** кампанию: `settlements()`,
`armies()`, `factions()`, `map()`, `date()`. Менять её можно только командами
через `apply` и концом хода `end_turn`.
